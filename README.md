# ProfitFinder

A simple web app to calculate profit from your sales.

## How to Use

1. Enter your revenue and cost in the form.
2. Click "Calculate Profit" to instantly see your profit.

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Relentless73/profitfinder-site.git
   cd profitfinder-site
   ```
2. Open `index.html` in your browser.

## Deploy on GitHub Pages

1. Commit all your files to the `main` branch.
2. Go to your repo on GitHub:  
   **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder.
4. Click **Save**.
5. Your site will be published at:
   ```
   https://relentless73.github.io/profitfinder-site/
   ```

## Customization

- Edit `index.html` for your own branding or calculations.
- Add CSS/JS as needed.
- Update this `README.md` for more documentation.
